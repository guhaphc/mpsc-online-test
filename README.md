# MPSC / UPSC AI Answer Checker

Initial Next.js frontend for the MPSC/UPSC learning and AI descriptive-answer evaluation platform.

Planned pipeline:
1. Registration/login
2. Admin approval
3. Question-paper upload
4. Answer-sheet upload
5. Automatic question-paper vs answer-sheet classification
6. Marathi/English OCR
7. Automatic question-answer matching
8. AI evaluation and second-pass verification
9. Marks, feedback and teacher review

Supabase AI evaluation tables are already prepared separately in the project database.
